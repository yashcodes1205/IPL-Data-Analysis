🏏 IPL Data Analysis (2008 - 2024)

📋 Project Overview

This project performs a deep dive into the Indian Premier League (IPL) historical dataset. Using Python's data science stack, I analyzed over 1,000 matches and 260,000+ deliveries to uncover the trends that define one of the world's most popular sports leagues.

🚀 Key Features

* Data Cleaning: Handled rebranding of franchises (e.g., Delhi Daredevils → Delhi Capitals) and standardized venue names to ensure historical accuracy.

* Performance Metrics: Visualized top run-getters (led by Virat Kohli) and wicket-takers (led by Yuzvendra Chahal).

* Match Insights: Analyzed the "Toss Factor," discovering that winning the toss only leads to a win 51% of the time.

* Over-by-Over Analysis: Explored how scoring rates and wicket distributions change from the Powerplay to the Death Overs.

🛠️ Tech Stack

* Language: Python

* Libraries: Pandas, NumPy, Matplotlib, Seaborn

* Platform: Google Colab / Jupyter Notebook

📈 Top Insights

* Consistency is King: Mumbai Indians and Chennai Super Kings dominate the "Most Titles" leaderboard, showing the value of a stable core team.

* Home Ground Advantage: Cities like Mumbai and Kolkata have hosted the most matches, creating a unique "fortress" effect for home teams.

* The Rebranding Effect: Data shows that teams often see a shift in "Success Ratio" following major franchise rebrands.

📂 How to use this project

* Clone the repository.

* Ensure you have matches.csv and deliveries.csv in the root folder.

* Run the IPL_analysis.ipynb notebook.
